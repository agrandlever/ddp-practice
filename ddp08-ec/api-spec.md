# API設計書：ECサイト商品管理

## 1. 基本情報

### 1.1 ベースURL

アプリケーションルートを基準とする。

商品管理機能では、`/products`を共通パスとして使用する。

### 1.2 認証方式

認証なし。

ユーザー認証は今回の対象外とする。

### 1.3 レスポンス形式

画面表示にはHTML（Thymeleaf）を使用する。

---

# 2. エンドポイント一覧

| HTTPメソッド | パス                            | 概要                                   | Controllerメソッド |
| ------------ | ------------------------------- | -------------------------------------- | ------------------ |
| `GET`        | `/products`                     | 商品一覧を表示する                     | `list()`           |
| `GET`        | `/products?category={category}` | カテゴリで絞り込んだ商品一覧を表示する | `list()`           |
| `GET`        | `/products/new`                 | 商品登録画面を表示する                 | `showCreateForm()` |

| `GET`        | `/products/{id}/edit`           | 商品編集画面を表示する                 | `showEditForm()`   |
| `POST`       | `/products/{id}`                | 商品を更新する                         | `update()`         |
| `POST`       | `/products/{id}/delete`         | 商品を削除する                         | `delete()`         |

# 3. エンドポイント詳細

## 3.1 GET /products

### 概要

登録済みの商品を一覧表示する。

カテゴリが指定された場合は、指定カテゴリの商品だけを表示する。

### クエリパラメータ

| 項目       | 型       | 必須   | 内容                   |
| ---------- | -------- | ------ | ---------------------- |
| `category` | `String` | いいえ | 絞り込み対象のカテゴリ |

許可値：

- `食品`
- `日用品`
- `家電`
- `書籍`
- `その他`

`category`が指定されていない場合は、全商品を表示する。

### 正常時

HTTPステータス：

`200 OK`

テンプレート：

`products/list`

Model属性：

| 項目               | 型              | 内容                       |
| ------------------ | --------------- | -------------------------- |
| `products`         | `List<Product>` | 表示対象の商品一覧         |
| `categories`       | `List<String>`  | カテゴリ選択肢             |
| `selectedCategory` | `String`        | 現在選択されているカテゴリ |

商品が0件の場合は、

`商品はありません`

と表示する。

### 不正なカテゴリ値

定義されていないカテゴリが指定された場合は、その値では検索しない。

商品一覧画面を再表示し、

`指定されたカテゴリは使用できません。`

と表示する。

## 3.2 GET /products/new

### 概要

商品登録画面を表示する。

### 正常時

HTTPステータス：

`200 OK`

テンプレート：

`products/form`

Model属性：

| 項目          | 型             | 内容                     |
| ------------- | -------------- | ------------------------ |
| `productForm` | `ProductForm`  | 商品入力フォーム         |
| `categories`  | `List<String>` | カテゴリ選択肢           |
| `isNew`       | `boolean`      | 新規登録かどうか。`true` |

新規登録時の販売状態は「販売中」を初期値とする。

## 3.3 POST /products

### 概要

入力された商品情報を検証し、新しい商品を登録する。

### Content-Type

`application/x-www-form-urlencoded`

### リクエスト項目

| 項目          | 型        | 必須 | 条件              |
| ------------- | --------- | ---- | ----------------- |
| `name`        | `String`  | 必須 | 1～200文字        |
| `price`       | `Integer` | 必須 | 0～9,999,999      |
| `description` | `String`  | 任意 | 制限なし          |
| `category`    | `String`  | 必須 | 定義済み5カテゴリ |
| `onSale`      | `Boolean` | 必須 | `true` / `false`  |

### バリデーション

#### name

```java
@NotBlank
@Size(max = 200)
```

#### price

```java
@NotNull
@Min(0)
@Max(9999999)
```

#### category

```java
@NotBlank
```

さらに、次の5種類のいずれかであることを確認する。

- 食品
- 日用品
- 家電
- 書籍
- その他

#### onSale

```java
@NotNull
```

販売状態は必須とし、`true`または`false`のいずれかを受け取る。

未選択の場合は、

`販売状態を選択してください。`

と表示する。

### 正常時

商品を保存する。

HTTPステータス：

`302 Redirect`

遷移先：

`/products`

### バリデーションエラー

商品を保存しない。

HTTPステータス：

`200 OK`

テンプレート：

`products/form`

Model属性：

| 項目          | 型             | 内容                                     |
| ------------- | -------------- | ---------------------------------------- |
| `productForm` | `ProductForm`  | 入力された商品情報とバリデーションエラー |
| `categories`  | `List<String>` | カテゴリ選択肢                           |
| `isNew`       | `boolean`      | 新規登録なので`true`                     |

動作：

- 入力値を保持する
- 商品登録画面を再表示する
- 問題のある項目付近にエラーメッセージを表示する

## 3.4 GET /products/{id}

### 概要

指定された商品の詳細を表示する。

### パスパラメータ

| 項目 | 型     | 内容   |
| ---- | ------ | ------ |
| `id` | `Long` | 商品ID |

### 正常時

HTTPステータス：

`200 OK`

テンプレート：

`products/detail`

Model属性：

| 項目      | 型        | 内容       |
| --------- | --------- | ---------- |
| `product` | `Product` | 対象の商品 |

表示項目：

- 商品名
- 価格
- 説明
- カテゴリ
- 販売状態
- 登録日時
- 更新日時

### 商品が存在しない場合

商品詳細画面は表示しない。

Flash属性：

| 項目           | 型       | 内容                   |
| -------------- | -------- | ---------------------- |
| `errorMessage` | `String` | `商品が見つかりません` |

HTTPステータス：

`302 Redirect`

遷移先：

`/products`

リダイレクト後の商品一覧画面で、

`商品が見つかりません`

と表示する。

# 5. カテゴリ定義

使用できるカテゴリは次の5種類とする。

- 食品
- 日用品
- 家電
- 書籍
- その他

商品登録・商品編集・カテゴリフィルタで同じ定義を使用する。

# 6. Controller設計

## ProductController

Springアノテーション：

```java
@Controller
@RequestMapping("/products")
```

`@Controller`は、このクラスをSpring MVCのControllerとして扱う指定。

`@RequestMapping("/products")`は、このController内の各URLへ共通して`/products`を付ける指定。

### 担当する処理

- 商品一覧表示
- カテゴリフィルタ
- 商品登録
- 商品詳細表示
- 商品編集
- 商品削除

| メソッド           | 対応エンドポイント           |
| ------------------ | ---------------------------- |
| `list()`           | `GET /products`              |
| `showCreateForm()` | `GET /products/new`          |
| `create()`         | `POST /products`             |
| `showDetail()`     | `GET /products/{id}`         |
| `showEditForm()`   | `GET /products/{id}/edit`    |
| `update()`         | `POST /products/{id}`        |
| `delete()`         | `POST /products/{id}/delete` |
