# テスト仕様書：ECサイト商品管理

## 1. 基本情報

### 1.1 対象システム

ECサイト商品管理

### 1.2 テスト目的

要件定義書、機能仕様書、API設計書、DB設計書、画面設計書に定義された商品管理機能が、設計どおりに動作することを確認する。

主に次を確認する。

- 商品一覧
- 商品追加
- 商品詳細
- 商品編集
- 商品削除
- カテゴリ別フィルタ
- 入力バリデーション
- 境界値
- 価格表示
- 存在しない商品へのアクセス

---

# 2. テスト環境

- OS：Windows
- ブラウザー：Google Chrome
- Java：Java 21
- Spring Boot：本演習で採用したバージョン
- データベース：H2 Database（インメモリ）
- 文字コード：UTF-8

# 4. テストケース詳細

## TC-001｜商品一覧を表示する

**種別：** 正常系・画面表示
**優先度：** 高

### 前提条件

- 初期データが登録されている。

### 手順

1. `/products`へアクセスする。

### 期待結果

- `SCR-001｜商品一覧画面`が表示される。
- 登録済みの商品が一覧表示される。
- 各商品について次が表示される。
  - 商品名
  - 価格
  - カテゴリ
  - 販売状態
- 商品名が商品詳細画面へのリンクになっている。
- 価格がカンマ区切り＋`円`で表示される。
- 販売中の商品は`販売中`と表示される。
- 販売停止の商品は`販売停止`と表示される。

### 確認例

DB値：

`3980`

画面表示：

`3,980円`

---

## TC-002｜商品を新規登録する

**種別：** 正常系
**優先度：** 高

### 前提条件

- `SCR-001｜商品一覧画面`が表示されている。

### 手順

1. `商品を追加`を押す。
2. `SCR-002｜商品登録画面`が表示されることを確認する。
3. 次を入力する。

```text
商品名：キーボード
価格：5980
説明：USB接続のキーボード
カテゴリ：家電
販売状態：販売中
```

4. `登録`を押す。

### 期待結果

- 入力エラーが発生しない。
- 商品がDBへ保存される。
- 商品一覧画面へ遷移する。
- `キーボード`が一覧へ表示される。
- 価格が`5,980円`と表示される。
- カテゴリが`家電`と表示される。
- 販売状態が`販売中`と表示される。

## TC-007｜商品を編集する

**種別：** 正常系
**優先度：** 高

### 前提条件

- 編集対象の商品が登録されている。
- 商品詳細画面が表示されている。

### 手順

1. `編集`を押す。
2. 商品編集画面が表示されることを確認する。
3. 現在の商品情報がフォームへ入力済みであることを確認する。
4. 商品名を変更する。
5. 販売状態を`販売中`から`販売停止`へ変更する。
6. `更新`を押す。

### 期待結果

- `POST /products/{id}`が実行される。
- 商品情報がDBで更新される。
- 商品詳細画面へ遷移する。
- 変更後の商品名が表示される。
- 販売状態が`販売停止`と表示される。
- `created_at`は変更されない。
- `updated_at`は更新される。

## TC-008｜商品を削除する

**種別：** 正常系・代替
**優先度：** 高

### 前提条件

- 削除対象の商品が登録されている。
- 商品詳細画面が表示されている。

### 手順1：キャンセル

1. `削除`を押す。
2. 確認ダイアログが表示される。
3. `キャンセル`を選択する。

### 期待結果1

- 商品は削除されない。
- 商品詳細画面に留まる。
- 商品がDBに残っている。

### 手順2：削除

1. 再度`削除`を押す。
2. 確認ダイアログで`OK`を選択する。

### 期待結果2

- `POST /products/{id}/delete`が実行される。
- 商品がDBから削除される。
- 商品一覧画面へ遷移する。
- 削除した商品が一覧に表示されない。

---

2. `絞り込む`を押す。

### 期待結果2

- カテゴリによる絞り込みが解除される。
- 全商品が一覧表示される。

# 5. 今回テストケースを設けない仕様

次の仕様は設計書には残すが、今回の11件には独立したテストケースを設けない。

- 商品説明が`NULL`の場合
- カテゴリに定義外の値を直接送信した場合
- 商品編集時の商品名・価格バリデーション
- 存在しない商品IDに対する編集
- 存在しない商品IDに対する削除
- 商品が0件の場合の`商品はありません`表示

これらは仕様から削除するものではなく、今回の基本テスト対象から外すだけとする。
