# 画面設計書：ECサイト商品管理

## 1. 基本情報

### 1.1 対象システム

ECサイト商品管理

### 1.2 画面設計方針

- 管理者が商品情報を分かりやすく確認・操作できる画面とする。
- Bootstrap 5を使用してレイアウトを整える。
- 商品登録画面と商品編集画面では同じThymeleafテンプレートを使用する。
- 入力エラーは該当する入力項目の近くへ表示する。
- 商品価格はカンマ区切りにし、末尾へ`円`を付けて表示する。
- 商品削除では、削除要求を送信する前に確認ダイアログを表示する。
- カテゴリは自由入力ではなくプルダウンから選択する。

# 2. 画面一覧

| 画面ID    | 画面名       | URL                   | Thymeleafテンプレート | 概要                                 |
| --------- | ------------ | --------------------- | --------------------- | ------------------------------------ |

# 3. SCR-001｜商品一覧画面

## 3.1 基本情報

| 項目         | 内容                                   |
| ------------ | -------------------------------------- |
| 画面ID       | `SCR-001`                              |
| 画面名       | 商品一覧画面                           |
| URL          | `/products`                            |
| HTTPメソッド | `GET`                                  |
| テンプレート | `products/list`                        |
| 主な目的     | 商品の一覧確認とカテゴリによる絞り込み |

## 3.2 表示項目

画面上部に次を表示する。

- 画面タイトル：`商品管理`
- カテゴリ選択
- `絞り込む`ボタン
- `商品を追加`ボタン

商品一覧には次を表示する。

| 項目     | 表示内容                             |
| -------- | ------------------------------------ |
| 商品名   | 商品名。商品詳細画面へのリンクとする |
| 価格     | カンマ区切り＋`円`                   |
| カテゴリ | 商品カテゴリ                         |
| 販売状態 | `販売中`または`販売停止`             |

## 3.3 レイアウト例

```text
商品管理

[ カテゴリ：すべて ▼ ] [ 絞り込む ]        [ 商品を追加 ]

---------------------------------------------------------
商品名             価格          カテゴリ     販売状態
---------------------------------------------------------
ミネラルウォーター   120円         食品         販売中
ワイヤレスマウス     3,980円       家電         販売中
Java入門書          2,800円       書籍         販売停止
---------------------------------------------------------
```

## 3.4 商品名

商品名を選択した場合、

`GET /products/{id}`

を実行し、`SCR-003｜商品詳細画面`へ遷移する。

## 3.5 商品追加

`商品を追加`を押した場合、

`GET /products/new`

を実行し、`SCR-002｜商品登録画面`へ遷移する。

## 3.6 カテゴリフィルタ

カテゴリは`select`要素を使用する。

選択肢：

- すべて
- 食品
- 日用品
- 家電
- 書籍
- その他

`食品`を選択して絞り込んだ場合の例：

```text
GET /products?category=食品
```

カテゴリ未指定または`すべて`の場合は全商品を表示する。

## 3.7 商品が0件の場合

一覧部分へ、

`商品はありません`

と表示する。

## 3.8 不正なカテゴリ

定義されていないカテゴリ値が指定された場合は、

`指定されたカテゴリは使用できません。`

とエラーメッセージを表示する。

## 3.9 エラーメッセージ

存在しない商品IDが指定された処理から商品一覧へリダイレクトされた場合は、

`商品が見つかりません`

と表示する。

このメッセージはリダイレクト後の1回だけ表示する。

# 4. SCR-002｜商品登録画面

## 4.1 基本情報

| 項目               | 内容             |
| ------------------ | ---------------- |
| 画面ID             | `SCR-002`        |
| 画面名             | 商品登録画面     |
| URL                | `/products/new`  |
| 表示HTTPメソッド   | `GET`            |
| 登録エンドポイント | `POST /products` |
| テンプレート       | `products/form`  |
| 主な目的           | 新しい商品の登録 |

## 4.2 入力項目

| 項目     | HTML要素              | 必須   | 条件              |
| -------- | --------------------- | ------ | ----------------- |
| 商品名   | `input type="text"`   | はい   | 1～200文字        |
| 価格     | `input type="number"` | はい   | 0～9,999,999      |
| 説明     | `textarea`            | いいえ | 任意              |
| カテゴリ | `select`              | はい   | 定義済み5カテゴリ |
| 販売状態 | `radio`               | はい   | 販売中／販売停止  |

## 4.3 初期値

新規登録時の販売状態は、

`販売中`

を選択済みとする。

カテゴリは初期状態では、

`選択してください`

を表示する。

## 4.4 レイアウト例

```text
商品登録

商品名
[                                      ]

価格
[                                      ] 円

説明
[                                      ]
[                                      ]
[                                      ]

カテゴリ
[ 選択してください ▼ ]

販売状態
(●) 販売中
( ) 販売停止

[ 登録 ]  [ キャンセル ]
```

## 4.5 登録

`登録`を押した場合、

`POST /products`

へ入力内容を送信する。

登録成功後は、

`SCR-001｜商品一覧画面`

へ遷移する。

## 4.6 キャンセル

`キャンセル`を押した場合は商品を保存せず、

`SCR-001｜商品一覧画面`

へ戻る。

## 4.7 バリデーションエラー

入力値が不正な場合は、

- 商品を保存しない
- 入力済みの値を保持する
- 商品登録画面を再表示する
- 該当する入力項目の近くへエラーを表示する

### 商品名未入力

```text
商品名
[                                      ]
商品名を入力してください。
```

### 商品名が200文字超過

`商品名は200文字以内で入力してください。`

### 価格未入力

`価格を入力してください。`

### 価格が範囲外

`価格は0～9,999,999の整数で入力してください。`

### カテゴリ未選択

`カテゴリを選択してください。`

### 販売状態未選択

`販売状態を選択してください。`

# 5. SCR-003｜商品詳細画面

## 5.1 基本情報

| 項目         | 内容               |
| ------------ | ------------------ |
| 画面ID       | `SCR-003`          |
| 画面名       | 商品詳細画面       |
| URL          | `/products/{id}`   |
| HTTPメソッド | `GET`              |
| テンプレート | `products/detail`  |
| 主な目的     | 選択商品の詳細確認 |

## 5.2 表示項目

| 項目     | 表示内容                 |
| -------- | ------------------------ |
| 商品名   | 商品名                   |
| 価格     | カンマ区切り＋`円`       |
| 説明     | 商品説明                 |
| カテゴリ | 商品カテゴリ             |
| 販売状態 | `販売中`または`販売停止` |
| 登録日時 | `created_at`             |
| 更新日時 | `updated_at`             |

## 5.3 レイアウト例

```text
商品詳細

商品名       ワイヤレスマウス
価格         3,980円
説明         USB接続のワイヤレスマウス
カテゴリ     家電
販売状態     販売中
登録日時     2026/09/14 12:00
更新日時     2026/09/14 12:00

[ 編集 ] [ 削除 ] [ 一覧に戻る ]
```

## 5.4 編集

`編集`を押した場合、

`GET /products/{id}/edit`

を実行して、

`SCR-004｜商品編集画面`

へ遷移する。

## 5.5 削除

`削除`を押した場合、すぐには削除要求を送信しない。

ブラウザーの確認ダイアログへ、

`この商品を削除しますか？`

と表示する。

### OK

`POST /products/{id}/delete`

を実行する。

削除成功後は商品一覧画面へ遷移する。

### キャンセル

削除処理を行わず、商品詳細画面に留まる。

## 5.6 一覧に戻る

`一覧に戻る`を押した場合、

`GET /products`

で商品一覧画面へ戻る。

## 5.7 商品が存在しない場合

商品一覧画面へリダイレクトし、

`商品が見つかりません`

と表示する。

# 6. SCR-004｜商品編集画面

## 6.1 基本情報

| 項目               | 内容                  |
| ------------------ | --------------------- |
| 画面ID             | `SCR-004`             |
| 画面名             | 商品編集画面          |
| URL                | `/products/{id}/edit` |
| 表示HTTPメソッド   | `GET`                 |
| 更新エンドポイント | `POST /products/{id}` |
| テンプレート       | `products/form`       |
| 主な目的           | 登録済み商品の編集    |

## 6.2 入力項目

商品登録画面と同じ入力項目を使用する。

- 商品名
- 価格
- 説明
- カテゴリ
- 販売状態

## 6.3 初期表示

保存済みの商品情報を入力済みの状態で表示する。

例：

```text
商品編集

商品名
[ ワイヤレスマウス                   ]

価格
[ 3980                              ] 円

説明
[ USB接続のワイヤレスマウス          ]

カテゴリ
[ 家電 ▼ ]

販売状態
(●) 販売中
( ) 販売停止

[ 更新 ]  [ キャンセル ]
```

## 6.4 更新

`更新`を押した場合、

`POST /products/{id}`

へ入力内容を送信する。

正常に更新された場合、

`SCR-003｜商品詳細画面`

へ遷移し、更新後の商品情報を表示する。

## 6.5 更新日時

更新成功時は、

- `created_at`は変更しない
- `updated_at`を更新する

## 6.6 キャンセル

商品情報を更新せず、

`SCR-003｜商品詳細画面`

へ戻る。

## 6.7 バリデーションエラー

登録画面と同じバリデーションを使用する。

入力エラーの場合は、

- DBを更新しない
- 入力値を保持する
- 商品編集画面を再表示する
- エラーを該当入力項目付近へ表示する

## 6.8 商品が存在しない場合

商品一覧画面へリダイレクトし、

`商品が見つかりません`

と表示する。

---

# 7. 登録・編集フォームの共用

商品登録画面と商品編集画面は、

`products/form`

を共通テンプレートとして使用する。

新規登録の場合：

- 画面タイトル：`商品登録`
- 実行ボタン：`登録`

編集の場合：

- 画面タイトル：`商品編集`
- 実行ボタン：`更新`

画面側で新規・編集を区別するため、

`isNew`

を使用する。

# 8. 画面遷移

```text
SCR-001 商品一覧画面
    │
    ├─ 商品を追加
    │      ↓
    │  SCR-002 商品登録画面
    │      │
    │      ├─ 登録成功
    │      │      ↓
    │      │  SCR-001 商品一覧画面
    │      │
    │      └─ キャンセル
    │             ↓
    │         SCR-001 商品一覧画面
    │
    └─ 商品名を選択
           ↓
       SCR-003 商品詳細画面
           │
           ├─ 編集
           │    ↓
           │ SCR-004 商品編集画面
           │    │
           │    ├─ 更新成功
           │    │      ↓
           │    │  SCR-003 商品詳細画面
           │    │
           │    └─ キャンセル
           │           ↓
           │       SCR-003 商品詳細画面
           │
           └─ 削除
                ↓
             確認ダイアログ
                │
                ├─ OK
                │   ↓
                │ SCR-001 商品一覧画面
                │
                └─ キャンセル
                    ↓
                  SCR-003 商品詳細画面
```

カテゴリフィルタでは画面遷移せず、`SCR-001`の商品一覧だけを更新する。

# 9. 画面とエンドポイントの対応

| 操作             | HTTPメソッド | パス                            | 結果            |
| ---------------- | ------------ | ------------------------------- | --------------- |
| 商品一覧表示     | `GET`        | `/products`                     | `SCR-001`       |
| カテゴリ絞り込み | `GET`        | `/products?category={category}` | `SCR-001`       |
| 商品登録画面     | `GET`        | `/products/new`                 | `SCR-002`       |
| 商品登録         | `POST`       | `/products`                     | 登録後`SCR-001` |
| 商品詳細         | `GET`        | `/products/{id}`                | `SCR-003`       |
| 商品編集画面     | `GET`        | `/products/{id}/edit`           | `SCR-004`       |
| 商品更新         | `POST`       | `/products/{id}`                | 更新後`SCR-003` |
| 商品削除         | `POST`       | `/products/{id}/delete`         | 削除後`SCR-001` |

| `価格は0～9,999,999の整数で入力してください。` | `SCR-002` / `SCR-004` | 価格が範囲外        |

| `販売状態を選択してください。`                 | `SCR-002` / `SCR-004` | 販売状態未選択      |
