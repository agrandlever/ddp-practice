# 機能仕様書：ECサイト商品管理

## 1. 前提

- 本システムはECサイトの商品管理機能を対象とする。
- 利用者はECサイトの商品を管理する管理者とする。
- ユーザー認証は今回の対象外とする。
- カート、注文・決済、商品画像アップロード、在庫管理は対象外とする。
- 商品データはH2のインメモリDBへ保存する。
- アプリケーション終了時に商品データが失われることを許容する。

---

# 3. ユースケース

## UC-001｜商品を登録する

### アクター

管理者

### 事前条件

- 管理者が商品一覧画面を表示できる。

### 事後条件

- 正常に登録された商品がDBへ保存されている。
- 登録した商品を商品一覧で確認できる。

### 正常系フロー

1. 管理者が`SCR-001｜商品一覧画面`を表示する。
2. 管理者が「商品を追加」を押す。
3. システムは`SCR-002｜商品登録画面`を表示する。
4. 管理者が次の商品情報を入力する。
   - 商品名
   - 価格
   - 説明
   - カテゴリ
   - 販売状態
5. 管理者が「登録」を押す。
6. システムは入力内容を検証する。
7. システムは商品をDBへ保存する。
8. システムは`SCR-001｜商品一覧画面`へ遷移する。
9. 登録した商品を一覧へ表示する。

### 代替フロー

#### 6a｜入力内容にエラーがある

1. システムは商品を保存しない。
2. 入力済みの値を保持する。
3. `SCR-002｜商品登録画面`を再表示する。
4. 問題のある項目付近にエラーメッセージを表示する。
5. 管理者は入力内容を修正して再度登録できる。

## UC-002｜商品一覧を確認する

### アクター

管理者

### 事前条件

なし。

### 事後条件

- 登録済みの商品を一覧で確認できる。

### 正常系フロー

1. 管理者が`/products`へアクセスする。
2. システムは登録済みの商品を取得する。
3. システムは`SCR-001｜商品一覧画面`を表示する。
4. 各商品について次を表示する。
   - 商品名
   - 価格
   - カテゴリ
   - 販売状態

### 表示ルール

価格はカンマ区切りにして末尾へ`円`を付ける。

例：

- `1980` → `1,980円`
- `39800` → `39,800円`

### 代替フロー

#### 2a｜商品が1件も存在しない

1. システムは商品一覧を空の状態で表示する。
2. `商品はありません`と表示する。

---

## UC-003｜商品詳細を確認する

### アクター

管理者

### 事前条件

- 対象の商品が存在する。

### 事後条件

- 選択した商品の詳細情報を確認できる。

### 正常系フロー

1. 管理者が商品一覧から商品名を選択する。
2. システムは対象商品のIDを受け取る。
3. システムは対象商品を取得する。
4. システムは`SCR-003｜商品詳細画面`を表示する。
5. 次の情報を表示する。
   - 商品名
   - 価格
   - 説明
   - カテゴリ
   - 販売状態
   - 登録日時
   - 更新日時

### 代替フロー

#### 3a｜指定された商品が存在しない

1. システムは通常の商品詳細を表示しない。
2. システムは`商品が見つかりません`をリダイレクト先へ渡す。
3. システムは`SCR-001｜商品一覧画面`へリダイレクトする。
4. 商品一覧画面で`商品が見つかりません`と表示する。

---

## UC-004｜商品を編集する

### アクター

管理者

### 事前条件

- 編集対象の商品が存在する。

### 事後条件

- 正常に更新された商品情報がDBへ保存されている。

### 正常系フロー

1. 管理者が`SCR-003｜商品詳細画面`を表示する。
2. 管理者が「編集」を押す。
3. システムは対象商品の現在値を取得する。
4. システムは現在値を入力済みの状態で`SCR-004｜商品編集画面`を表示する。
5. 管理者が商品情報を変更する。
6. 管理者が「更新」を押す。
7. システムは入力内容を検証する。
8. システムは商品情報を更新する。
9. `updated_at`を更新する。
10. `created_at`は変更しない。
11. システムは`SCR-003｜商品詳細画面`へ遷移する。
12. 更新後の商品情報を表示する。

### 代替フロー

#### 7a｜入力内容にエラーがある

1. システムは商品情報を更新しない。
2. 管理者が入力した値を保持する。
3. `SCR-004｜商品編集画面`を再表示する。
4. 問題のある項目付近にエラーメッセージを表示する。

#### 3a｜編集対象の商品が存在しない

1. システムは編集画面を表示しない。
2. システムは`商品が見つかりません`をリダイレクト先へ渡す。
3. システムは`SCR-001｜商品一覧画面`へリダイレクトする。
4. 商品一覧画面で`商品が見つかりません`と表示する。

---

## UC-005｜商品を削除する

### アクター

管理者

### 事前条件

- 削除対象の商品が存在する。

### 事後条件

- 削除を承認した場合、対象商品がDBから削除されている。

### 正常系フロー

1. 管理者が`SCR-003｜商品詳細画面`を表示する。
2. 管理者が「削除」を押す。
3. システムは削除確認ダイアログを表示する。
4. 管理者が削除を承認する。
5. システムは対象商品を削除する。
6. システムは`SCR-001｜商品一覧画面`へ遷移する。
7. 削除した商品が一覧に表示されないことを確認できる。

### 代替フロー

#### 4a｜削除をキャンセルする

1. 管理者が確認ダイアログでキャンセルする。
2. システムは商品を削除しない。
3. 商品詳細画面に留まる。

#### 5a｜削除対象の商品が存在しない

1. システムは削除処理を行わない。
2. システムは`商品が見つかりません`をリダイレクト先へ渡す。
3. システムは`SCR-001｜商品一覧画面`へリダイレクトする。
4. 商品一覧画面で`商品が見つかりません`と表示する。

---

## UC-006｜カテゴリで商品を絞り込む

### アクター

管理者

### 事前条件

- 商品一覧画面を表示できる。

### 事後条件

- 選択したカテゴリに該当する商品のみを確認できる。

### 正常系フロー

1. 管理者が`SCR-001｜商品一覧画面`を表示する。
2. 管理者がカテゴリを選択する。
3. 管理者が「絞り込む」を押す。
4. システムは指定されたカテゴリの商品を取得する。
5. システムは該当する商品だけを一覧表示する。

使用できるカテゴリ：

- 食品
- 日用品
- 家電
- 書籍
- その他

### 代替フロー

#### 2a｜「すべて」を選択する

1. システムはカテゴリによる絞り込みを行わない。
2. すべての商品を表示する。

#### 4a｜指定カテゴリの商品が存在しない

1. 商品一覧を空の状態で表示する。
2. `商品はありません`と表示する。

#### 2b｜定義されていないカテゴリ値が送信される

1. システムはそのカテゴリで検索しない。
2. 商品一覧画面を再表示する。
3. カテゴリが不正であることを示すエラーメッセージを表示する。

# 5. 画面遷移

```text
SCR-001 商品一覧画面
    │
    ├─ 商品を追加
    │      ↓
    │  SCR-002 商品登録画面
    │      ↓ 登録成功
    │  SCR-001 商品一覧画面
    │
    └─ 商品を選択
           ↓
       SCR-003 商品詳細画面
           │
           ├─ 編集
           │    ↓
           │ SCR-004 商品編集画面
           │    ↓ 更新成功
           │ SCR-003 商品詳細画面
           │
           └─ 削除
                ↓ 削除承認
              SCR-001 商品一覧画面
```

# 6. ビジネスルール

| ルールID | ルール名         | 内容                                                  |
| -------- | ---------------- | ----------------------------------------------------- |
| `BR-001` | 商品名           | 必須。1～200文字とする                                |
| `BR-002` | 価格             | 必須。0～9,999,999円の整数とする                      |
| `BR-003` | 説明             | 任意とする                                            |
| `BR-004` | カテゴリ         | 食品・日用品・家電・書籍・その他の5種類のみ使用できる |
| `BR-005` | 販売状態         | 必須。販売中または販売停止とする                      |
| `BR-006` | 販売状態の初期値 | 新規登録時は販売中とする                              |
| `BR-007` | 価格表示         | カンマ区切りにし、末尾に`円`を付ける                  |
| `BR-008` | 商品削除         | 削除前に確認し、承認された場合だけ削除する            |
| `BR-009` | 存在しない商品   | 詳細表示・編集・削除を通常処理として実行しない        |
| `BR-010` | カテゴリ未指定   | カテゴリを指定しない場合は全商品を表示する            |
| `BR-011` | 登録日時         | 商品登録時に設定し、商品編集時には変更しない          |
| `BR-012` | 更新日時         | 商品登録時に設定し、商品編集時に更新する              |
