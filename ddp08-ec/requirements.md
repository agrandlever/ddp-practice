# 要件定義書：ECサイト商品管理

## 1. 文書情報

- プロジェクト名：ECサイト商品管理
- 作成日：2026-09-14
- 作成者：学習者
- バージョン：1.0

---

## 2. プロジェクト概要

### 2.1 背景・目的

ECサイトで扱う商品情報を一元管理し、管理者がブラウザから商品の登録・確認・編集・削除を簡単に行えるようにする。

また、カテゴリで商品を絞り込み、必要な商品を確認しやすくする。

### 2.2 対象ユーザー

ECサイトの商品を管理する管理者。

---

## 3. スコープ

### 3.1 対象範囲

本システムでは、次の商品管理機能を対象とする。

- 商品追加
- 商品一覧
- 商品詳細
- 商品編集
- 商品削除
- カテゴリ別フィルタ

### 3.2 対象外

次の機能は今回の対象外とする。

- ユーザー認証
- カート
- 注文・決済
- 商品画像アップロード
- 在庫管理

---

## 4. 機能要件

| ID     | 機能名             | 説明                                             | 優先度 |
| ------ | ------------------ | ------------------------------------------------ | ------ |
| FR-001 | 商品追加           | 管理者が商品情報を入力して新しい商品を登録できる | 高     |
| FR-002 | 商品一覧           | 登録済みの商品を一覧で確認できる                 | 高     |
| FR-003 | 商品詳細           | 選択した商品の詳細情報を確認できる               | 高     |
| FR-004 | 商品編集           | 登録済みの商品情報を変更できる                   | 高     |
| FR-005 | 商品削除           | 登録済みの商品を確認後に削除できる               | 高     |
| FR-006 | カテゴリ別フィルタ | 商品一覧をカテゴリで絞り込める                   | 中     |

---

## 5. 商品情報

商品は次の情報を持つ。

| 項目     | 必須 | 条件                             |
| -------- | ---- | -------------------------------- |
| 商品名   | 必須 | 1～200文字                       |
| 価格     | 必須 | 0～9,999,999円の整数             |
| 説明     | 任意 | 商品の説明                       |
| カテゴリ | 必須 | 食品・日用品・家電・書籍・その他 |
| 販売状態 | 必須 | 販売中・販売停止                 |

### 5.1 販売状態

新しい商品を登録する場合、販売状態の初期値は「販売中」とする。

### 5.2 価格表示

画面上では価格をカンマ区切りにし、末尾に「円」を付けて表示する。

例：

- `1980` → `1,980円`
- `39800` → `39,800円`

---

## 6. 入力エラー

入力内容が条件を満たさない場合、商品を保存しない。

エラー発生時は次のように処理する。

- 入力済みの値を保持する
- 入力画面を再表示する
- 問題のある項目付近にエラーメッセージを表示する

---

## 7. カテゴリ別フィルタ

商品一覧画面でカテゴリを選択できるようにする。

使用できるカテゴリは次の5種類とする。

- 食品
- 日用品
- 家電
- 書籍
- その他

カテゴリを指定しない場合は、すべての商品を表示する。

---

## 8. 商品削除

商品を削除する前に確認を行う。

管理者が削除を承認した場合のみ商品を削除する。

キャンセルした場合は削除しない。

---

## 9. 非機能要件

### 9.1 利用環境

- OS：Windows
- ブラウザー：Google Chrome
- 文字コード：UTF-8

### 9.2 データベース

学習用としてH2 DatabaseのインメモリDBを使用する。

アプリケーションを終了した場合、保存された商品データが失われることを許容する。

## 11. 受け入れ基準

- [ ] 商品を新規登録できる
- [ ] 登録済みの商品を一覧表示できる
- [ ] 商品の詳細情報を確認できる
- [ ] 商品情報を編集できる
- [ ] 商品を確認後に削除できる
- [ ] カテゴリを指定して商品を絞り込める
- [ ] 商品名や価格などの不正な入力を登録できない
- [ ] 価格がカンマ区切り＋「円」で表示される
- [ ] 販売中・販売停止の状態を確認、変更できる
