# 要件定義書: オンラインじゃんけん

## 1. プロジェクト概要

### 1.1 背景・目的

Webブラウザだけで簡単に対戦できるようにする。

### 1.2 対象ユーザー

友人同士でじゃんけん対戦をしたい一般ユーザー。

## 2. 機能要件

| ID | 機能名 | 説明 | 優先度 |
|---|---|---|---|
| FR-001 | 対戦開始 | 対戦相手とオンラインでじゃんけん対戦を開始できる | 高 |
| FR-002 | 手の選択 | グー・チョキ・パーから自分の手を選択できる | 高 |
| FR-003 | 勝敗判定・表示 | 双方が手を選んだら、勝敗を判定して表示できる | 中 |

## 3. 非機能要件

### 3.1 パフォーマンス

指定なし。

## 4. 技術スタック

| レイヤー・用途 | 技術 |
|---|---|
| バックエンド | Java / Spring Boot |
| フロントエンド | HTML / CSS / JavaScript |
| テンプレートエンジン | Thymeleaf |
| データベース | 使用しない |
| その他 | 指定なし |

### 4.1 データ保持方針

本システムではデータベースを使用しない。

対戦参加者および対戦状態に関するデータは永続化せず、アプリケーション実行中のみ管理する。

そのため、アプリケーションを再起動した場合、それまでの対戦状態が失われることを許容する。

## 5. 受け入れ基準

- [ ] 2人のユーザーが同じ対戦に参加し、じゃんけんを開始できる。
- [ ] 各ユーザーがグー・チョキ・パーのいずれかを選択できる。
- [ ] 双方が手を選択した後、お互いの出した手及び勝ち・負け・あいこの結果が正しく表示される。
